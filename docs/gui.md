# 本地浏览器工作台

运行 `tutor gui`，在本机浏览器管理课程。GUI 与 CLI 共用同一份课程资料、教学路线、学习者记忆和导出文件。

```sh
tutor --env-file "$HOME/.config/tutor/env" gui --ocr mistral --data-dir .tutor
```

默认打开 `http://127.0.0.1:4318`。`--port` 可改端口，`--port 0` 自动分配空闲端口；`--no-open` 只打印地址。按 Ctrl+C 停止。`--agent-dir`、`--model`、OCR 服务地址及显式环境文件的语义与 CLI 一致，已有环境变量优先。发行版已内嵌界面资源，运行时无需 Node.js、pnpm 或网络前端服务器。

## 操作流程

1. 在「导入课程资料」填写课程名，选择 PDF，并指定物理页码或完整书签标题。可添加最多 12 张 PNG/JPEG/WebP 截图；单次文件合计不超过 120 MB。也可先建立空课程，系统会立即生成并持久化稳定课程 ID。同一课程可反复追加资料；相同资料不重复建章节，不同版本分开保留。
2. 资料解析后，在课程详情查看教学路线和课件章节。无标题或同名歧义会显示「章节名待确认」，在页面确认唯一标题前不能确认路线或生成该章讲解。可提交调整意见，或「保存路线，稍后继续」。
3. 点击「确认并生成讲解稿」。确认时 Tutor 校验完整章节清单；正在学习和已学完章节的标题、位置、来源版本与已有讲解不会被模型路线替换。
4. 在「讲解稿」提交局部反馈，修订成功后更新导出；失败沿用 CLI 的暂存和已发布文件保护。新资料尚未确认时仍可下载上一次导出。
5. 在「教学路线」的章节列表中明确标记「未开始 / 正在学 / 已学完」，并可为单个章节生成或重新生成 `chapters/<章节 ID>/output/` 下的独立讲解。生成、打开或下载讲解不会改变学习进度。
6. 「学习反馈」用于保存或查询学习者记忆。「环境与配置」运行本地 doctor，不调用模型/OCR，也不校验在线凭据有效性。

刷新或关闭浏览器不停止任务。重开 GUI 后使用原任务继续；待确认仍等待，已完成结果不会因重开而重新生成，显式取消不会复活。运行中的 GUI 持有整个数据目录的写入所有权，直接 CLI 写入会被拒绝。

## 边界

- 服务只监听 `127.0.0.1`，拒绝不匹配的 Host、跨站 Origin 和缺失的会话标识；不提供远程访问配置。每次重启后刷新页面以获取新会话。
- GUI 一次执行一个任务，避免并发写入和沙箱状态冲突。原有 CLI 仍可独立使用。
- 上传的资料按现有流程发送至所选 OCR/模型服务；凭据只由本地环境和 Pi 配置读取，页面不提供凭据编辑。
- 浏览器文字预览不执行 HTML 或载入外部图片；数学公式、表格和插图以导出的 PDF 为准。
- 任务身份、阶段、决定和结果持久保存；任务区显示有界日志。课程资料、原始输入与输出保存在磁盘。

## 开发

主程序与 GUI 共用 Bun 1.4.4+、根工作区和根 `bun.lock`。前端由 CQU Moe Design 生成器创建，本地 `.design/` 发布包和主题覆盖项随源码提交。

```sh
bun install --frozen-lockfile
bun run --filter @cqu-moe/tutor-gui build
bun run check:design
bun run typecheck
bun run gui --no-open
```

前端修改后重新运行 GUI 构建并重启 GUI。独立的 Vite 开发服务器没有 Tutor 会话，不作为可用工作台入口。`bun run build` 会先构建前端，再将其编入所有请求的可执行文件。GUI HTTP 集成测试在 `test/gui.test.js`；同样支持 `TUTOR_TEST_BINARY` 验证打包产物。

## 保存的任务与中断

工作台与 CLI 使用同一任务身份。刷新或关闭浏览器不取消；重新启动工作台会接回保存的任务。任务区显示已完成、待确认、取消或需要处理，以及对应操作。没有接纳记录的旧工作保留待处理，不自动执行。修订本章只修改选定章节。工作台持有整个数据目录的写入所有权，直接 CLI 必须等待其关闭；详见 [任务中断续跑](task-resumption.md)。
