# Domain Docs

本项目使用 single-context，沿用已有领域术语表。

## 探索前读取

- 根目录 `GLOSSARY.md`。
- `docs/adr/` 中与当前工作相关的 ADR。

文件或目录不存在时直接继续，不单独报告缺失，也不预先创建占位文档。术语或有实质取舍的决策明确后，由 `domain-modeling` 等技能按需维护。

## 布局

- `GLOSSARY.md`：课程讲解领域的词汇、定义和应避免的近义词。
- `docs/adr/`：需要保存决策理由时按需创建。
- 不使用多领域映射或按包拆分的术语表。

## 使用领域词汇

Issue 标题、规格、设计和测试中的领域概念使用术语表定义的名称，不使用其明确避免的同义词。新概念先判断是否已有对应术语；确有缺口时再补充。

## ADR 冲突

如拟议改动与已有 ADR 冲突，明确指出冲突及重新讨论的理由，不静默覆盖原决策。

## 后续维护

可直接编辑本项目的领域文档和 `docs/agents/` 配置。只有切换 issue tracker 或希望重新初始化约定时才需要再次运行 setup。
