# Triage Labels

技能使用五个标准角色，本项目保留同名标签。

| 标准角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格充分，可交由 Agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不计划处理 |

技能要求应用某个角色时，使用上表对应的标签字符串。后续更名时更新此映射，避免产生重复标签。
