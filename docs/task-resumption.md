# 教学任务中断续跑

CLI 和 GUI 共用已接纳教学任务。接纳前，原始上传文件和修订原稿已复制到任务拥有的位置，官方 Pi 事务才创建任务并保存请求索引。任务记录绑定课程 UUID、课程/章节版本、原模型与本地配置目录引用、OCR 端点、原反馈和暂存区，不保存凭据。

```sh
tutor --data-dir .tutor tasks --json
tutor --data-dir .tutor --task-id ID --resume
tutor --data-dir .tutor --task-id ID --confirm
tutor --data-dir .tutor --task-id ID --cancel
tutor --data-dir .tutor --task-id ID --retry
```

`tasks` 列出任务身份、阶段、状态、原因与继续命令，不执行任务或调用供应商。`--course NAME --resume` 优先选择该课程待确认的路线，否则选择最新教学任务；存在多条任务时用 `--task-id` 明确选择。记忆维护可以用 `--memory "resume" --resume` 接回原请求。新传入的模型参数不会替换已接纳任务的配置引用。凭据仍从原本机配置与当前进程环境解析；改变 `PI_MEMORY_DIR` 时先恢复原目录设置。

状态含义：

| 状态 | 下一步 |
| --- | --- |
| `running` | 正在执行；GUI 可刷新或重新打开页面 |
| `awaiting-route` | 阅读路线并确认、提出调整或取消；重启仍等待 |
| `needs-attention` | 查看原因；已知安全的本地失败可 `--retry`；未知外部/工具结果需检查保留工件，取消后再明确提交新工作 |
| `succeeded` | 结果已提交；重开不会重新生成 |
| `cancelled` | 显式取消的终态，不会自动复活 |
| `failed` | 官方任务已失败，检查保留输入与原因 |

关闭浏览器、刷新页面和关闭执行者均不是取消。GUI 启动后接回原任务；CLI 用原任务身份继续。同一数据目录只能有一个写入执行者，包括 GUI 的课程修改端点；GUI 开着时用工作台查看状态或先关闭执行者再用 CLI。外部文档命令的监督进程持有同一 OS 锁描述符；Tutor 意外退出时先终止其命令进程组，随后才释放所有权。锁文件不会被删除或按 PID 猜测回收。

MinerU 已知 batch 继续查询，已完成缓存复用；中断时没有 batch ID、上传结果无法核对，或 Mistral 同步响应未知时均暂停。已接收原始 OCR 结果先保存，再建立可校验缓存。不会因未知响应自动重复提交，也没有无限后台重试。模型沿用官方 Pi 有界重试/重启限制；供应商请求或费用不承诺恰好一次。

生成和修订复用原官方会话、原反馈与原暂存区。记忆使用原工具任务身份核对效果；未完成的任意 bash/edit/write 不盲目重放。stage 命令只获得文档工具需要的环境，并禁止读取配置凭据目录；文件读取继续遵守课程与历史边界。

导出先验证完整候选文件树并保存清单，再替换旧输出。重开核对候选、旧文件树和当前输出，补完发布或保留可核对的旧输出；Markdown、Typst、PDF、图片和 `lecture.json` 属于同一套结果。准备失败重用已完成的讲解源，不重新生成。修订指定 `--chapter-id` 或 GUI 中的本章时，仅发布到该章节。

旧版本的无接纳记录暂存、上传和会话只显示为待处理，保留原文件，不自动执行或删除。用户明确选择 `--resume` 或 GUI 继续旧路线时，先复制仍可用的资料、创建新的接纳记录，再等待路线确认；不会重放旧会话或旧工具。这里覆盖进程中断，不提供误删、磁盘损坏、设备丢失或远程备份恢复。完整旧版、双课程和发行验收另见后续发布记录。
