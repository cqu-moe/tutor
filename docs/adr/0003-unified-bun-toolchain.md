# 主程序与 GUI 统一 Bun 工具链

本轮采用 Bun 统一主程序和 GUI 的依赖安装、脚本执行、构建、测试与 CI，使用一份根锁文件，以减少构建入口和工具版本的分叉。该决定取代 ADR 0001 中保留 GUI 独立 pnpm/Node 开发工具链的例外，继续保留 Bun 单文件发行方式。

GUI 与主程序共用根工作区和 `bun.lock`；本地设计系统包、主题覆盖项、`esbuild` 与 `@parcel/watcher` 构建许可保留在 Bun 配置中。安装、GUI 构建、设计检查、类型检查、测试与 CI 均显式由 Bun 执行，业务命令不依赖 Node 或 pnpm。先前规格草稿中的“统一 pnpm”方案作废。
