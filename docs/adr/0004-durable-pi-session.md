# 可重开的 Pi 教学会话

状态：本条记录 #15 会话适配阶段。下文“暂经适配”“本票不承担”和旧路线选择描述保留阶段背景；当前记忆效果身份与安全重放见 [ADR 0005](0005-scoped-learner-memory.md)，教学任务接纳、课程隔离会话、单写者及 CLI/GUI 恢复见 [ADR 0006](0006-teaching-task-lifecycle.md)。

教学路线使用锁定的官方 `pi-durable@1.4.0` 和官方 SQLite 后端，数据位于课程目录的 `.durable/session.sqlite`。长会话不采用把完整历史保留在内存中的 JSONL 后端，也不另建通用任务日志或工作流数据库。`openTutorDurableSession` 是后续任务、课程记忆工具接入的单一适配入口，支持注册官方扩展和在官方事务中提交业务文档。

兼容期保留 Pi 0.82.1 的本机模型与凭据解析，通过明确锁定的 Pi AI 1.4.0 alias 执行模型流。凭据不进入会话配置和恢复文档。原有四个记忆工具暂经适配接入；读取可以安全重放，写入、删除、恢复标为不可安全重放。中断时由官方任务状态判断哪些结果已经完成；结果未知的写操作不能当成成功，也不能自动重做。

公开 `--resume` 查回原提交，绕过重复导入资料的短路分支。官方 `submissionByRequest` 是唯一的 request→submission 索引。一个官方会话文档仅保存草稿上下文及当前章节身份、标题的摘要与当前路线请求 ID，用于在首次提议和后续调整间选中应等待的请求；它不保存 submission ID 或复制提交状态。选择先落盘、再接纳提交，避免已接纳的调整因进程退出而被旧指针遮蔽。选择已落盘但提交尚未接纳时，不创造新提交；旧版没有接纳记录的草稿仍只展示原路线并等待确认。

每次新导入通过官方 reset 开始新的模型上下文，避免上一份资料的调整污染下一份路线。恢复不 reset，不重新提交模型输入，不把待确认路线当作已确认。明确修正章节标题后，旧模型答案不能覆盖新的标题权威。课程章节标题和保护规则继续由课程状态层严格验证。

模型错误可能回显凭据。适配器在流事件和最终结果进入 Harness 前丢弃错误正文及附带内容，只保留数值 HTTP 状态、上下文溢出、可重试或不可重试的固定分类；官方有界重试和压缩策略仍适用。流中 partial 是共享可变对象，转发前须生成快照，不能让之后的 provider 变更穿透持久化边界。不能依赖 CLI 脱敏或关闭后的数据库清理。

Bun 1.4.4 对 Pi AI 1.4.0 的 `sideEffects` 标注会裁掉 telemetry 初始化。保留对公开 `AI_TELEMETRY_SCHEMA.version` 的可观察检查，兼顾初始化和版本诊断；不全局关闭 DCE。发行兼容性以搬移到消费者目录、移走源码依赖后的原生单文件恢复回归为准。跨平台编译不能替代其他平台的实际运行验证。

本票不承担数据目录的跨进程单写入者、完整业务任务接纳或课程记忆迁移；这些由后续票通过同一适配入口接入。模型中断后可能重发请求，不承诺供应商调用或计费恰好一次。
